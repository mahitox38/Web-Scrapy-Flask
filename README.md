# Price Comparison Website with Scrapy & Flask
This project is a **price comparison website** that scrapes product data from a website using **Scrapy** and displays the result through a **Flask web application**.
The application collects product prices, images, availabilitys, and categories.

**Features**
* Web scraping with Scrapy
* Automatic price updates
* Flask web app to display data
* Stores scraped data in JSON fromat
* Scrapes product categories, prices...

## Next Features 
* Automatic price updates using crone jobs
* Store data in an SQLite database
* API endpoints for external applications
* Improve frontend with Bootstrap
